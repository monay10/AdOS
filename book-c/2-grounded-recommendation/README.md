## Reading order

1. **`DECISION_JOURNAL.md`** — the shipped surface everything else enriches.
2. **`PERFORMANCE_ROLLUPS.md`** — the quantified evidence a recommendation stands on.
3. **`ALTERNATIVES_AND_TRADEOFFS.md`** — what else was considered, and why it lost.
4. **`DECISION_EXPLANATION.md`** — turning those facts into a faithful, readable "because".

## The one thing to remember

The "because" must be **found, not fabricated**. Every number comes from the agency's own
campaign data; the AI only phrases it. Evidence points the way — it never dictates it.
