# AdOS — Partner Ecosystem

The complete program for selling, implementing, supporting, and growing **AdOS — the
Enterprise AI Operating System for Advertising** through partners. It lets AdOS be
installed and operated by qualified partners on the customer's own infrastructure.

> **Single source of truth:** [`../PRODUCT_TRUTH.md`](../PRODUCT_TRUTH.md). No
> document here promises a capability AdOS does not implement today; future
> capabilities appear only under explicit **Roadmap** labels.
>
> **The product shape that governs everything here:** AdOS is **self-hosted,
> offline-first, and 100% local-AI** with **no cloud, no API keys, no per-token
> billing, and no phone-home telemetry**. Partners therefore earn from **license
> resale + implementation services + support + referral fees — never cloud/usage
> metering**. AdOS **drafts** human-approved advertising campaigns (it never launches
> live ads), and the **Company Brain** is a marketing-performance memory, not a
> document knowledge base.

## Shared vocabulary (defined authoritatively in the Constitution)

- **Partner types:** Referral · Reseller · Implementation · *(Roadmap)* Technology/ISV.
- **Organizational tiers:** Registered → Silver → Gold → Platinum.
- **Individual credentials (feed the tiers):** ACA → ACP → ACAD → ACAR → ACPT → ACT
  (defined in `../customer-success/CERTIFICATION_PROGRAM.md`).
- **Implementation (10 phases):** Discovery → Planning → Installation → Configuration
  → Migration → Training → Go-live → Hypercare → Acceptance → Closure.
- **Support severity:** Sev 1 Critical → Sev 4 Low (partner Tier-1 / vendor Tier-2;
  SLA = vendor **response** time).
- **Revenue:** license resale margin · services (partner-retained) · support/managed
  services · referral fees. **No cloud/usage metering.**

## Relationship to the rest of the repo

The partner program builds on the **Customer Success** package

([`../sales/`](../sales/)) and **marketing** ([`../marketing/`](../marketing/))
collateral. All of it is governed by [`../PRODUCT_TRUTH.md`](../PRODUCT_TRUTH.md).
